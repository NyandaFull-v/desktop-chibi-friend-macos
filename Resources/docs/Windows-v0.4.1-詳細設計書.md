# デスクトップちびフレンド v0.4.1 詳細設計書

## 1. 目的

v0.3.16の機能と保存データを維持し、Windows 11上での常駐メモリを大幅に削減する。完全オフライン、展開型配布、将来のキャラクター差し替えを前提とする。

## 2. 実行構成

- 常駐本体はC++/Win32の単一exe。
- .NET/WPFランタイムは使用しない。
- キャラ、コイン、アイテムは、それぞれ画像の周囲だけを覆う小型レイヤードウィンドウ。
- 設定画面は必要時だけ同一プロセス内で生成し、閉じると破棄する。
- OBS用ページはOBS起動中だけローカルHTTPサーバーを開始する。
- 通信先は `127.0.0.1` のみ。外部通信は行わない。

## 3. メモリ方針

- PNGはWindows Imaging Componentで直接32bit premultiplied BGRAへ変換。
- 通常立ち絵は現在の1コマだけを保持。
- アニメーションは現在の系列4コマだけを保持し、状態変更時に前系列を即時解放。
- 透過用の仮想デスクトップ全面バッファを作らない。
- 状態切り替え後に不要なワーキングセットをWindowsへ返す。
- 設定画面とOBSサーバーは常時確保しない。

## 4. ウィンドウ

| 種類 | 大きさ | 入力 |
|---|---:|---|
| キャラ | 設定値×設定値（初期180px） | 左クリック、ドラッグ、なでる、右クリック |
| コイン | 54×54px | ドラッグのみ |
| アイテム | 96×96px | ドラッグのみ |
| 洞窟 | 180×180px | 演出専用 |
| 吹き出し | 文章に応じて150～520px | クリックで即時消去。通常会話の約20%で放物線状に投げる |

## 5. 状態機械

通常、ドラッグ、落下、よじ登り、アラート、買い物、怒って帰宅、全画面退避、OBS休憩、システム一時停止を排他的に管理する。

- 通常：歩く、ダッシュ、座る、寝る、きょろきょろ、掘る、転ぶ、歌う。
- ドラッグ：カーソルへ直接追従。離した時の速度を投擲速度にする。
- 落下：重力を加え、画面下または通常ウィンドウ上端へ着地。
- よじ登り：対象ウィンドウ側面を上昇。登頂成功と再落下は1:1。
- アラート：通常行動を停止し、上下に激しく跳ねる。クリックで解除。
- 帰宅：現在位置に洞窟を出し、入った後にキャラと洞窟を消す。
- OBS休憩：デスクトップ側の全オブジェクトを非表示にする。
- システム一時停止：ロック・スリープ中は全更新を止める。

## 6. 地形判定

- 最大化されていない可視トップレベルウィンドウの上端を足場とする。
- 最大化ウィンドウ、ツールウィンドウ、不可視・最小化・クローク状態を除外。
- Fences 4はクラス名先頭 `Fences` で除外。
- ウィンドウ自体は一切移動しない。
- 接触時は3:1で落下、1:3でつかむ。つかんだ後は1:1で登頂または落下。
- モニター端では隣接画面へダイブし、上から落下状態で入る。
- 全モニターの作業領域下端を常時地面として保持し、隣接画面でも着地判定を失わない。
- 回収不能位置へ落ちた場合はメインモニター中央上から落下状態で復帰。

## 7. 入力

- 左クリック：つんつん。5分以内に10回で怒る。
- 左ドラッグ：つまんで移動。カーソルへの追従を維持。
- 頭上を左長押しして小さく左右往復：なでる。
- 右クリック：設定画面。
- デスクトップの空白を右ダブルクリック：所持アイテムを完全ランダムで召喚。
- 帰宅中のみ、デスクトップ空白の左トリプルクリックでも呼び戻せる。
- デスクトップアイコン上、ウィンドウ上のクリックは無視。

## 8. コイン・アイテム・買い物

- コイン出現は最短1分、最長60分の設定範囲から毎回ランダム。
- 上から落下し、画面下または小ウィンドウ上へ着地。1時間で消滅。
- 掘る行動中は低確率で直接残高へ1枚追加。
- 初期所持品は水色のリボン、クッキー、猫じゃらし。
- 3系統×5品、計15品。
- 10枚以上あるとき、5枚で未取得品優先の買い物を行う。
- 買った品を5秒間見せびらかし、まだ10枚以上なら次の買い物を予約。

## 9. 時計機能

- 毎時0分に「○時だよ！」。
- アラームはHH:MM形式の1件、1回限り。発火後に無効化。
- OBS中は効果音なし。
- アラームはゲーム・全画面退避より優先して対象画面上部へ表示。
- ポモドーロ初期値は集中25分、休憩5分、4回。
- 全画面開始時はポモドーロ自体を終了。

## 10. ゲーム・全画面・OBS

- ゲーム判定はSteam/Epic/GOG/XboxGames配下の前景実行ファイルに限定し、一般アプリの誤判定を抑える。
- 前景ウィンドウがモニター全域を覆う場合は全画面扱い。
- 対象画面にいる場合、別モニターへ退避。別モニターがなければ洞窟へ帰宅。
- OBSプロセスの起動・終了を2秒間隔で確認。
- OBS中は `http://127.0.0.1:設定ポート/` で透過ブラウザソースを提供。

## 11. 保存と互換性

- `data/settings.json` と `data/profile.json` を使用。
- v0.3.16の主要キー、日時形式、ItemCounts形式を読み書き可能。
- コイン、所持品、所持数、次回出現時刻、最終位置を移行。
- 配布ZIPには `data` とログを含めない。

## 12. 品質確認

- 全9ポーズ、全32アニメーションコマ、全15アイテム、コインの計57セルをWICでデコードして非空を検査。
- 設定とプロフィールの互換読込を検査。
- 連続稼働中の応答、CPU時間、ワーキングセット、専用メモリを実測。
- 最終配布物から個人データが除外されていることを一覧検査。
