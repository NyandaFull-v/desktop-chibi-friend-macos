# デスクトップちびフレンド v0.4.1-mac

Windows版 v0.4.1 を完成版として固定し、同じキャラクター資産と保存内容を macOS 13 以降へ移植した版です。完全オフラインで動きます。Mac版は Windows版とは別フォルダ・別保存先なので、Windows版を上書きしません。

GitHub Releasesには、GitHubのmacOS環境でコンパイル・簡易署名した配布ZIPを掲載します。ソースから作る場合は次の手順を利用してください。

## 対応環境

- macOS 13 Ventura 以降
- Apple Silicon（M1以降）および Intel Mac
- 1台以上のモニター。増減・配置変更に追従
- Mac App Store用のSandboxアプリではありません

## Macでアプリを作る

1. Mac App StoreからXcodeを入れ、一度起動して利用規約を確認します。
2. この `DesktopChibiFriendMac` フォルダをMacへコピーします。
3. 「ターミナル」を開き、このフォルダへ移動します。
4. `bash build-macos.sh` を実行します。
5. `dist/デスクトップちびフレンド.app` が完成します。

初回だけ、アプリをControlキーを押しながらクリックして「開く」を選んでください。自作の簡易署名なので通常のダブルクリックではmacOSが確認を求める場合があります。Gatekeeper自体を無効にする必要はありません。

## 初回の許可

右ダブルクリックの召喚、デスクトップ空白判定、ウィンドウ上端の検出のため「システム設定 → プライバシーとセキュリティ」で本アプリを「アクセシビリティ」と「入力監視」に許可します。macOSの版によっては入力監視が表示されない場合があり、その場合はアクセシビリティだけで構いません。許可後にアプリを一度終了して起動し直してください。画面収録、マイク、カメラ、外部ネット接続の許可は不要です。

## 操作方法

- ちび堕ふるを左クリック：つんつん。5分以内に10回で怒って洞窟へ帰ります。
- 頭付近を左長押しして小さく左右往復：なでます。
- 左ドラッグ：つまんで移動し、放した勢いで投げます。
- ちび堕ふるを右クリック：設定画面を開きます。
- デスクトップの何もない所を右ダブルクリック：所持品からランダムで1個召喚します。前の召喚品は消えます。
- 怒って帰宅中、何もない所を左トリプルクリック：呼び戻します。
- 吹き出しをクリック：すぐ消します。アラーム中はアピールも止まります。
- メニューバーの🐾：設定、ポモドーロ、ダイス、終了を選べます。

デスクトップアイコンや通常ウィンドウ上の右ダブルクリックは召喚として扱いません。

## 主な機能

- 歩く、走る、座る、足をぱたぱた、寝る、きょろきょろ、転ぶ、歌う、掘る、壁をよじ登る
- 最大化されていないウィンドウの上端へ登り、座る。失敗すると落下
- モニター間を端からダイブして移動し、移動先の上から落下
- コインが設定間隔で上から出現。ウィンドウや画面下へ着地し、1時間後に消滅
- 掘ってごくまれにコインを発見
- コイン10枚以上で、5枚を使って未収集品優先の買い物
- 装飾品・お菓子・おもちゃ各5種。買った品を見せびらかす
- ランダム定型文、役に立ちにくい豆知識、設定頻度で「……たぶん」
- 毎時0分の時報、1件・1回限りのアラーム
- 集中25分／休憩5分／4回が初期値のポモドーロ
- 1d3、1d4、1d6、1d10、1d20、1d100
- OBS起動中は本体を休ませ、透過ブラウザソースだけを提供
- 全画面・ゲーム中の画面を避け、他のモニターへ退避
- ロック・スリープ中は全機能を一時停止
- ログイン時の自動起動

通常ウィンドウは一切動かしません。Fences 4はWindows専用ソフトなので、Mac版の判定対象には存在しません。

## OBS

OBS起動中だけ、設定画面に表示される `http://127.0.0.1:47831/`（初期値）をローカルのブラウザソースとして利用できます。歩行・コイン落下だけの簡易版です。本体はOBS終了まで休み、アラーム音も鳴りません。サーバーはMac内部の `127.0.0.1` だけで待ち受けます。

## 保存場所

`~/Library/Application Support/DesktopChibiFriend/` に `settings.json` と `profile.json` を保存します。アプリ本体を更新しても保存内容は残ります。初期所持品は水色のリボン、クッキー、猫じゃらしです。

Windows版のコインと所持品を移す場合は、Mac版の初回起動前にWindows版の `data` フォルダを `.app` と同じ場所へ置きます。Mac版に保存データがまだない場合だけ自動で読み込み、画面座標以外を引き継ぎます。

## 検査

Mac上で `bash validate-macos.sh` を実行すると、設定ファイル、画像一式、Swiftのコンパイル、作成済みアプリの署名構成を検査します。実際のモニター配置、アクセシビリティ許可、OBS連動は `MAC実機確認表.md` に沿って確認してください。
